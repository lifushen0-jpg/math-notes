# 对称群 $S_n$ 中元素的表示

## 1. $S_n$ 的元素是什么

令 $[n]=\{1,2,\ldots,n\}$。**对称群** $S_n$ 由 $[n]$ 到自身的所有双射组成，其群运算是映射的复合。这些双射称为**置换**。

例如，$S_5$ 中的置换
$$\sigma=\begin{pmatrix}1&2&3&4&5\\2&3&1&4&5\end{pmatrix}$$
表示
$$\sigma(1)=2,\quad \sigma(2)=3,\quad \sigma(3)=1,\quad \sigma(4)=4,\quad \sigma(5)=5.$$
两行表示法完整列出了每个数字的去向。

## 2. 循环记号

上述置换使 $1,2,3$ 按照
$$1\longrightarrow2\longrightarrow3\longrightarrow1$$
循环移动，而 $4,5$ 保持不变。因此可以简写为
$$\sigma=(1\ 2\ 3).$$

**读取规则：**在循环 $(a_1\ a_2\ \cdots\ a_k)$ 中，每个数字映到右边的数字，最后的 $a_k$ 映回 $a_1$；没有写出的数字保持不变。即
$$a_1\mapsto a_2,\quad a_2\mapsto a_3,\quad\ldots,\quad a_k\mapsto a_1.$$

因此，$(1\ 2\ 3)$ 是一个映射的记号，括号中数字的顺序决定映射的方向。例如
$$(1\ 2\ 3):\ 1\mapsto2,\ 2\mapsto3,\ 3\mapsto1;$$
$$(1\ 3\ 2):\ 1\mapsto3,\ 3\mapsto2,\ 2\mapsto1.$$
它们是不同的置换，并且互为逆置换。

从同一个循环中的不同位置开始写，不改变置换：
$$(1\ 2\ 3)=(2\ 3\ 1)=(3\ 1\ 2).$$

## 3. 不交循环分解

若一个置换使
$$1\mapsto3,\quad3\mapsto5,\quad5\mapsto1,\qquad2\mapsto4,\quad4\mapsto2,$$
则它包含两个互不相交的循环，可以写作
$$(1\ 3\ 5)(2\ 4).$$

其中 $(1\ 3\ 5)$ 表示 $1\to3\to5\to1$，$(2\ 4)$ 表示交换 $2$ 与 $4$。任意置换都可以写成若干个两两不交的循环之积；不动点对应长度为 $1$ 的循环，通常省略不写。

## 4. 置换的乘法

置换相乘指映射复合。约定**先作用右边，再作用左边**。例如，计算 $(1\ 2)(2\ 3)$：

- $1$ 先在 $(2\ 3)$ 下不变，再由 $(1\ 2)$ 送到 $2$，故 $1\mapsto2$；
- $2$ 先送到 $3$，再保持不变，故 $2\mapsto3$；
- $3$ 先送到 $2$，再送到 $1$，故 $3\mapsto1$。

所以
$$(1\ 2)(2\ 3)=(1\ 2\ 3).$$

**注** 长度为 $2$ 的循环称为**对换**。例如，$(1\ 2)$ 只交换 $1$ 与 $2$，其余数字不变。对有公共元素的循环，相乘的先后顺序通常会影响结果；计算时应逐个追踪数字的去向。
